Features

  • GNOME Desktop
  • Dash to Panel + ArcMenu
  • Brave Browser
  • Custom Xenon branding & Plymouth boot screen
  • Built using Penguins Eggs
Installer Notice
Older XenonOS previews used Calamares. Current releases use Penguins Eggs (Krill) because it more reliably preserves the customized XenonOS desktop.

Installing XenonOS

Download XenonOS ISO

1. Boot the Live ISO

Boot the USB and wait for the XenonOS desktop to load.

2. Check your display resolution

If anything looks stretched or blurry:

  • Open Settings → Displays
  • Select the correct resolution.
  • Apply the changes.

3. Open Terminal

Open Console from ArcMenu or the taskbar.

4. Start Krill

sudo eggs krill

The installer will guide you through:

  • Language
  • Keyboard
  • Disk Selection
  • User Creation
  • Password
  • Hostname
  • Summary

Verify everything carefully before confirming installation.

5. Wait for Installation

Krill will format the selected drive, install XenonOS, configure the bootloader, and complete setup automatically.

6. Restart

Restart the computer and remove the USB when prompted.

7. Log Into Your User

Do NOT log into the root account. Log into the user account you created during installation.

8. Optional Tweaks

Open Tweaks → Appearance.

Recommended cursor theme:

  • Breeze Cursors

9. Enjoy XenonOS

Your installation is complete.

Troubleshooting

  • If the desktop resolution looks wrong, adjust it in Settings → Displays.
  • If you closed the installer, simply run sudo eggs krill again.
  • If you accidentally log into root, sign out and use your normal account.
