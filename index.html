Installing XenonOS

Download XenonOS ISO

1. Boot the Live USB

Boot from your XenonOS USB and wait for the desktop to fully load.

2. Check Your Display Resolution

If the desktop appears stretched or blurry:

  • Open Settings → Displays
  • Select your monitor's native resolution.
  • Click Apply.

3. Launch the XenonOS Installer (Recommended)

Double-click the Install XenonOS icon on the desktop.

The Calamares installer will guide you through:

  • Language
  • Location & Timezone
  • Keyboard Layout
  • Disk Partitioning
  • User Account Creation
  • Installation Summary

Review everything carefully before clicking Install.

4. Wait for Installation

Calamares will copy XenonOS to your drive, install the bootloader, and configure your system automatically.

5. Restart

When the installation finishes, restart your computer and remove the USB drive.

6. Log Into Your Account

Do NOT log into the root account. Log into the user account you created during installation.

If Calamares Doesn't Work

If the Calamares installer fails to launch or closes unexpectedly, XenonOS includes a backup installer called Penguins Eggs Krill.

1. Open Terminal

Open Terminal from ArcMenu or the Applications menu.

2. Run the Backup Installer

sudo eggs krill

Press Enter and follow the prompts to complete the installation.

Krill will guide you through selecting your language, keyboard layout, installation drive, user account, and system configuration.

3. Finish Installation

After Krill completes, restart your computer, remove the USB drive, and log into your new XenonOS installation.

Optional Tweaks

Open GNOME Tweaks → Appearance.

Recommended cursor theme:

  • Breeze

Enjoy XenonOS!

Your installation is complete. Welcome to XenonOS!

Troubleshooting

  • If the desktop resolution looks wrong, adjust it in Settings → Displays.
  • If you closed the installer, simply run sudo eggs krill again.
  • If you accidentally log into root, sign out and use your normal account.
